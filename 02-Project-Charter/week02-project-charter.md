## Project Title

RCHN Patient Intake and Scheduling System Update

---

## Project Sponsor

Director

---

## Business Need

RCHN is using an aging patient intake and scheduling system across six clinics, and the current system is creating scheduling inconsistencies and workflow problems. NovaTech needs to work with clinic managers and staff to understand how these problems affect each location and identify where the current processes are creating difficulties. We know the system is aging and needs to be replaced, but we should not assume that every clinic is experiencing the same problems or that we already know how serious each issue is. Replacing the current system can provide RCHN with a more reliable platform and create more consistent intake and scheduling processes across all six clinics.

---

## Purpose and High-Level Scope

The purpose of this project is to replace the aging patient intake and scheduling system across all six RCHN clinics with a more reliable system that supports consistent workflows. The high-level scope includes patient intake, appointment scheduling, evaluation of the existing system and supporting infrastructure, staff training, and rollout support across all six clinics.

---

## Success Criteria

1. More consistent and efficient appointment scheduling across all six RCHN clinics.
2. Reduced patient wait times through improved intake and scheduling workflows.
3. A more reliable patient intake and scheduling system with fewer workflow disruptions and slowdowns.
